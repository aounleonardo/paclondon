# Vacant houses blob format (for Bill)

MVP borough is **Islington** (not Tower Hamlets).

Upload target on Netlify Blobs:

- **Store name:** `mazes`
- **Key:** `islington/vacant-houses`

Give Leonardo a JSON file that matches `islington-vacant-houses.sample.json`.
He will run:

```bash
npm run upload:vacant-houses -- path/to/your-file.json
```

## Required shape

```json
{
  "id": "islington",
  "label": "Islington",
  "kind": "vacant-houses",
  "generatedAt": "2026-11-07T00:00:00.000Z",
  "houses": [
    {
      "id": "is-001",
      "label": "Human-readable address or note",
      "lat": 51.555,
      "lng": -0.10833
    }
  ]
}
```

### Field rules

| Field | Required | Notes |
| --- | --- | --- |
| `id` | yes | Borough id. Use `islington`. |
| `label` | yes | Display name, e.g. `Islington`. |
| `kind` | yes | Must be `"vacant-houses"`. |
| `generatedAt` | yes | ISO-8601 timestamp. |
| `houses` | yes | Array (can be empty). |
| `houses[].id` | yes | Stable unique string. |
| `houses[].lat` | yes | WGS84 latitude (number). |
| `houses[].lng` | yes | WGS84 longitude (number). |
| `houses[].label` | optional | Address / description shown in UI later. |

Do **not** include `status` — the game sets that at runtime (`vacant` → `reported`).

## Important gameplay constraint

Houses must sit close to a playable road. The game drops houses farther than **~15 metres** from the maze road network, because the player can only travel on those roads.

The maze roads live in a separate blob:

- **Key:** `islington/maze`
- That file is generated by us; you do not need to edit it.
- Baked mazes include `graphBridgeVersion: 2` (≤5 m junction bridges). Refresh blob + `public/mazes/islington.json` with:

```bash
npm run rebake:islington:bridges:upload
```

(Requires `NETLIFY_SITE_ID` and `NETLIFY_AUTH_TOKEN` in `.env`.)
- Your houses should fall inside the Islington borough boundary and near real streets.

## Separate blobs (do not merge)

1. `islington/maze` — road graph / playable map (`vacantHouses` stays `[]` there)
2. `islington/vacant-houses` — **your** house list (this file)

The live app loads both and attaches reachable houses onto the maze.
